# Trash Sorter Pro v2.2.0 — User experience and Admin operations

## Highlights

- AI confidence now uses one consistent probability contract and renders correctly, for example `8.5%`.
- Bin notifications open the assigned station in the map without reloading the browser session.
- Eco-Share is now a cloud community: posts, likes, reposts, and comments are shared between authenticated users.
- Users can reveal password fields while typing and upload a private avatar.
- Admin Settings, Audio, and Logs are separate screens. Production uses the secured hardware bridge for settings, audio tests, and logs.
- Recognition no longer lets a short, block-shaped charger inherit the `Pen` specialist result. A user-confirmed charger reference resolves to `Cục sạc` → `Electronics` → `Vô cơ` (bin 2).
- Desktop and Web history now separate the Vietnamese display label from the immutable original YOLO class and expose review status/audit information.

## Recognition and history review

- Specialist detections can define a minimum aspect ratio. `Pen` requires an elongated box, preventing charger-sized rectangular objects from overriding the base electronics signal.
- A confirmed-sample promotion command stores reviewed camera frames as recognition-only references; it does not silently add screenshots or unreviewed queue images to training data.
- The 774-row local history was backed up before an idempotent label backfill. Original class, confidence, timestamps, images, ownership and ACK data remain unchanged.
- Backfill result: 618 model-inferred rows without full capture evidence, 138 rows requiring Admin review, 14 rows marked insufficient evidence and 4 rows verified from metadata. No display label is empty.
- Admin can review a row from Desktop or Web, choose a catalog label, add an audit note or explicitly mark the image as insufficient evidence. User is read-only.
- Apply `202606210008_history_review_labels.sql` before enabling cloud history review. The bridge synchronizes label fields during insert and conflict updates.

## Safety

- Avatar files accept JPG, PNG, and WebP only, are resized to 256px WebP, and are stored in a private bucket with signed URLs.
- Hardware bridge still denies remote servo calibration, sort tests, and Actuation Test Mode.
- User data remains scoped server-side; Admin-only bridge routes require a valid Admin session and bridge secret.

## Migration

Apply `202606210006_community_and_avatars.sql` before deploying this release. It adds community tables, `accounts.avatar_path`, indexes, and the private `account-avatars` bucket.

Then apply `202606210008_history_review_labels.sql` to add normalized history labels and review audit fields to cloud history.
