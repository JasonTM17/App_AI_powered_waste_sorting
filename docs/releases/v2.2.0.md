# Trash Sorter Pro v2.2.0 — User experience and Admin operations

## Highlights

- AI confidence now uses one consistent probability contract and renders correctly, for example `8.5%`.
- Bin notifications open the assigned station in the map without reloading the browser session.
- Eco-Share is now a cloud community: posts, likes, reposts, and comments are shared between authenticated users.
- Users can reveal password fields while typing and upload a private avatar.
- Admin Settings, Audio, and Logs are separate screens. Production uses the secured hardware bridge for settings, audio tests, and logs.

## Safety

- Avatar files accept JPG, PNG, and WebP only, are resized to 256px WebP, and are stored in a private bucket with signed URLs.
- Hardware bridge still denies remote servo calibration, sort tests, and Actuation Test Mode.
- User data remains scoped server-side; Admin-only bridge routes require a valid Admin session and bridge secret.

## Migration

Apply `202606210006_community_and_avatars.sql` before deploying this release. It adds community tables, `accounts.avatar_path`, indexes, and the private `account-avatars` bucket.
